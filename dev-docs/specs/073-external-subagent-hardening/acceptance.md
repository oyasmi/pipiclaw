## 实施结果

- B1 隔离继承的 Claude 嵌套标识、OAuth 凭据和路由配置，角色 `env:` 优先于适配器默认值。CLI 版本探测也使用过滤后的环境。Claude 优先读取 `result.errors`，Codex 将缓存读取从新增输入中拆出。
- B2 实时退出和重启接管共用失败分类与结算逻辑。完成唤醒、任务日志、任务步骤和两种委派详情均显示分类或下一步。执行前拒绝要求识别到结构化事件、事件流完整并且没有活动或非零用量的证据。未知、缺失或损坏的流按执行情况不明处理。
- B3 进度轮询每次最多读取 64 KiB。静默达阈值后才比较进程组 CPU，活跃后暂停采样两分钟，宿主机休眠从有效静默时长扣除。重启后重建探活状态。
- B4 先按工位内的任务或频道作用域检查在途委派，并在登记前预留同一匹配键，覆盖两次并发派发尚未写入记录的窗口。失效会话、登录、额度或模型配置造成的失败会拦截续接。六项不变量在测试检查点比较运行记录、磁盘和活跃租约。
