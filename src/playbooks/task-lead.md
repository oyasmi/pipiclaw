# 任务步骤：推进与交付

适用于有 task_report 的后台任务会话；普通聊天建档和管理读 `task-manage.md`。运行时负责调度、状态与记账，你负责 Goal 内的推进、判断、检查和交付。任务可自行实施或按收益委派，工作项可选。

没有 task_create、memory_save、event_manage 是执行边界，不换文件写入绕过。报告与提问只发任务投递频道；频道换绑期间步骤继续、投递暂存，不把持久化当成已经送达。

## 用 brief 启动，不重读已有材料

| 输入 | 用法 |
|---|---|
| task_contract | 首步、压缩后或正文改动后给完整契约；未丢失就复用 |
| task_state | 每步的预算、用量和在途工作 |
| task_inputs | 本次新结果、用户要求、卡顿、恢复或异常；无新输入可缺省 |
| task_board / task_log | 相关看板与最近记录；不足才 task_log，完整输出按给出的路径 read |
| previous_occurrence | 周期实例首步可能带上一实例的收尾与最后汇报，是衔接资料而非新指令 |

先落实新要求，再推进可执行工作。**步骤最后回复只记新增结论、证据、改动与检查、未决问题、下一动作或真实等待来源**；不复抄目标历史。运行时记入任务记录，不发给用户。

用 edit 维护 brief 的契约绝对路径：核查后勾 DoD，工作项用 `[ ]`、`[x]`、`[!]`、`[~]`，可追加 `- [ ] W4 …`，用 `→ dod:1,2` 引用标准。文件头归运行时，不改状态/预算；追加预算是用户操作。中间产物在 `<deskDir>/work/<taskId>/`，长期产物留本工位或目标项目，外部共享路径须明确写入范围。

委派才读 `agent-delegation.md`：本步启动的委派/作业自动绑定任务，相关派发带 item；独立工作可并行，仓库隔离写优先 worktree。dispatched 和执行者总结不代表完成。

## 只剩等待时

| 等什么 | 操作 |
|---|---|
| 本任务委派/作业 | 结束回合，运行时按在途工作等待；结果、卡顿或用户消息可叫醒你 |
| CI、文件出现等外部条件 | 一个带足够 timeout 的 bash async:true 作业作传感器，只查条件，成立或超时叫醒任务；同时最多一个 |
| 一个时刻 | task_wait until，例如 +12h；新结果/用户消息可提前继续 |
| 用户决定 | task_ask，问题具体并附建议选项；期间结果记下，用户回答后一起处理 |

只问阻止目标完成的缺项，用户已给足答案就继续，不追加无关确认；记录计划可保留原话，真正定时执行才需明确时刻。

task_ask、task_wait、task_close 成功后结束本轮；未调用且无在途工作时会立即开下一步。不要轮询、sleep、同步长命令或事件占住任务等条件；长测试用后台作业。

## 检查、返工与结束条件

对照 DoD 查真实产物、diff、检查输出和外部状态，说明对应版本、覆盖项与缺口。独立检查用 purpose=verify；带 item 只查该项及其引用 DoD，终验不带 item。看板 completed 和 VERDICT 都不代替证据。

FAIL 区分已证实缺陷与验证受阻：违反标准才返工，条件缺失就补验证；疑点先窄查，风格建议不扩范围。必需检查已完成且产物/环境未变就复用证据，有新改动、失败或具体风险才补查。

返工交代**现象 → 证据 → 违反标准 → 修复边界和已通过项 → 重验方法**。同一问题连续两轮失败且无新证据，缩小复现、换方法或执行者。达到标准且无未解决必修项就收尾，不因预算有余额继续润色。

## 汇报与副作用证据

有交付、重要变化或风险才 task_report（每步最多 3 条、每条 1500 字符）；需要决定用 task_ask。报告先保存、发送失败自动重试，不重复调用补发。能发附件才用 `outbound-media.md`，否则给可取件产物，不能把服务器路径当已交付。

投递是至少一次。发送、发布、部署或改外部对象前，核对 Goal 授权、真实目标状态和 task_log 成功记录；完成后在步骤末记目标标识、时间、证据。结果未知先核查，不盲目重放。

完成时按序：核查产物 → edit 勾满足的 DoD、更新工作项 → 确认无待办/受阻项和在途工作 → 本步 task_report 交付成果、检查与风险 → task_close outcome=complete，note 留结果和证据。放弃项标 `[~]` 并说明，不能说完成。关闭绑定本步最后报告，送达确认前只由运行时重试，不开模型步骤；回执提供历时、用量和统计。

目标不可行或不值得继续时 task_ask 请用户决定，同意后 cancel；已明确要求取消无需再问。周期实例改进、暂停/超时和重启后恢复时读 [任务恢复](task-recovery.md)；委派失败/lost 读 [委派恢复](delegation-recovery.md)。
