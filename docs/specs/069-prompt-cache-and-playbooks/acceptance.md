内置 worker 用 run ID 建立缓存亲和，并在完成或注册后启动失败时释放资源。父会话与 worker 共用请求适配器，Codex 模型、端点和请求头的指纹因此按会话 ID 保存，并随 SDK 会话资源清除。原单槽记录在请求交错时会漏掉父会话的路由变化。

外部 CLI 的续接标准输入只带本轮指令。Claude 保留系统提示词文件参数，非 flag 型 CLI 仅在首轮保存其实际发送的角色正文。一次性记忆请求显式使用 `cacheRetention: "none"`。`/context` 使用已加载会话的 SDK 用量，命中率为已读缓存除以普通输入、已读缓存和写入缓存之和。

任务仍通过工具门控选择相应指南。后台步骤的规则进入稳定提示词，完整 Brief 继续提供契约路径及主干指南入口。模型发送 `immediate` 时 SDK 在执行前返回参数错误，直接调用的领域校验及旧的 `preAction.timeout` 输入仍保留。端到端用例检查错误回到模型、回合继续且无事件落盘。
