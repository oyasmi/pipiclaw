# 工具定义精简与扁平 playbook 改写

日期：2026-11-17。基线 `b66286f`。落实[组织分析](2026-11-17-prompt-playbook-organization.md)的第 1、2 项；按用户后续要求，低频知识也使用同层独立 playbook，沿用原目录、metadata、工具门控和 read 加载。工具发现、会话激活、常驻 prompt 规则与预算未改动。

## 实现

- 精简 subagent_inline、event_manage 的顶层与字段说明，并消除普通 subagent、job、skill、task_list、task_create 的重复叙述。保留默认值、单位、作用范围、整体替换语义、角色优先和 bash 写入必须声明 write 等调用条件。工具数、字段、类型、必填项、约束与执行逻辑保持一致。
- task-manage 只向有 task_create 的聊天提供立项与管理；task-lead 只向有 task_report 的任务会话提供执行、等待、验收和交付。原 brief 仍直接指向 task-lead。
- 普通委派、事实存取、提醒与环境识别保留可直接执行的短流程；inline、委派恢复、事件模板、传感器、学习/技能创作、文件地图、工位/宿主操作和任务恢复各自成为独立 playbook，可直接从目录发现，也可按指南里的具体条件读取。
- 共 16 份顶层指南，不引入附录目录、嵌套加载、加载标记或新工具。目录描述压短，引用是普通 Markdown 链接；加载器、path guard、构建复制脚本均保持原样。
- 同步操作文档、现有目录/引用/样例测试与篇幅测量组合；评测依赖图覆盖拆出的文件，并修正原有退役 delegation.md 引用。未改评分器、控制样本或验收标准。
