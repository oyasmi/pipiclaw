# 测试质量与成本复盘

适用于删除重叠覆盖、引入新场景或优化执行时间。现行准入规则见 [AGENTS.md](../../AGENTS.md#test-layering)，评测控制与封存流程见[评测指南](../evals.md)。

## 按故障决定覆盖层

| 要防的回归 | 曾经容易误判的证据 | 保留的验证方式 |
| --- | --- | --- |
| 频道并发与历史串线 | 一个普通问答证明基本投递，但不触发频道重叠 | 让第一个频道的供应商请求挂起，第二个频道先进行，分别检查发送的上下文、投递和落盘 |
| 忙碌时新建会话 | 只检查命令返回确认，旧队列仍可能执行 | 在活跃步骤与旧队列存在时发送 `/new`，检查旧队列丢弃、新输入及重启后的活跃会话 |
| 崩溃时工作恢复 | 在同一进程重新初始化，旧回调、内存和文件句柄可能仍存在 | 在持久化中间点用 IPC 通知父进程后 SIGKILL，新 daemon 检查账务、消息顺序和真实供应商请求 |
| 工具权限或配置越界 | 守卫 mock 拒绝或不存在的文件自然读取失败 | 单测用真实的受限文件和哨兵验证拒绝；跨层风险检查实际供应商工具声明或真实磁盘副作用 |
| API 协议回归 | 在每项协议边界启动完整 agent，重复支付模型夹具成本 | 保留真实处理器和连接，在单测覆盖流并发上限、错误码、取消；正常 SDK、传输、运行时和投递组合由 e2e 验证 |
| 回答质量与实际副作用 | 固定人类文案，或看到结果文件便认定本轮成功 | 文案由共享结构测试覆盖。确定性 e2e 观察产物什么时候、由谁写入；评测验证内容及先后关系，并对评分器跑正、负与等价控制 |

有些看似很小的断言保护重要契约，例如 shell 转义、工具串行标记、实际落盘的会话 ID、日志的完整 JSONL 后缀。删除前应说明这一故障是否仍有覆盖。重复 fixture 可以共用，独立故障仍应各自有清楚的触发条件。

## 让测试确实经过失败路径

- 时间窗口由受控屏障驱动。并发场景等待前项实际进入，再释放后项。进程终止等待真实退出及进程组消失。持久化场景等待落盘或结算完成。
- 变异需要穿过整条保障链。测试内部代理工具越界时，两次仅放宽名单仍被后面的限制挡住。将故障注入 SDK 最终工具集后，真实供应商请求出现额外工具，断言才失败。编译错误、夹具超时和原本就会失败的前置条件单独记录。
- 长输入可以用同规模的高效夹具。把 150 条记忆批量写入，只重建一次索引，同时保留真实压缩逻辑、其边界输入和相关磁盘断言。
- 从真实入口验证接线。压缩恢复测试曾用 SDK 直调模拟 `/new`，移除运行时快照保存仍通过。改为经过公开传输入口后，变异能检出这处缺失。详见[记忆恢复复盘](./memory-consistency.md#验证证据)。
- 离线隔离持续到 shutdown。一次用例创建的目录、进程和观察句柄由该用例清理，关闭时的后台请求同样纳入未匹配请求检查。

## 历史数据及限制

10 月 13 日单元审计将 984 例降到 952 例。确定性 e2e 删除两个重复入口后，用频道并行隔离和忙碌新建会话补足缺口，仍为 55 例。10 月 30 日独立审计再净减 13 个 unit、1 个确定性 e2e、1 个离线评测工具链用例和 1 个手动 live 用例。

10 月 30 日同机、同依赖各跑三轮，单测墙钟中位数从 113.74 秒降到 105.26 秒，前后范围重叠，e2e 和 evals 中位数略升。WebSocket 单文件执行中位数从 14.21 秒降到 0.73 秒，记忆反思从 7.69 秒降到 1.51 秒。局部数据可定位 fixture 成本，全套运行时间还受构建、进程启动和机器负载影响。同套用例交错比较 `forks` 与 `threads` 也未发现稳定收益。

原始单测审计见 `83b593d:docs/reviews/2026-10-13-unit-test-pruning.md`，55 个 e2e 的逐项复核见 `b61465f:docs/reviews/2026-10-13-e2e-test-review.md`。后续测试审计和原始计时 JSON 见 `69acd35:docs/reviews/2026-10-30-test-quality-review.md`、`69acd35:docs/reviews/2026-10-30-test-quality-metrics.json`。
