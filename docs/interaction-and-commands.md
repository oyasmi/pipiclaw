# 交互与命令（Interaction and Commands）

> **适合谁**：希望顺畅使用终端、钉钉私聊/群聊与斜杠命令，掌握“助手忙时怎么插话纠偏、怎么分项目切工位、怎么随时接管后台工作”的用户。
> **前置**：已完成 [快速上手指南](./quickstart.md)。

---

## 三种使用入口如何协同

Pipiclaw 是**同一个个人助手**，提供三种同源入口：

1. **后台常驻服务（`pipiclaw` / `pipiclaw run`）**：默认开启本机 Web API，启用钉钉后同时维持钉钉 Stream 长连接，24 小时负责后台长程任务推进、定时事件触发与外部 Agent 完成唤醒。
2. **终端界面（`pipiclaw tui`）**：本机 Web API Socket 的官方客户端。**无论后台服务是否启动都能直接用**——有常驻服务时直接连上去共享状态；没有时在当前终端内自动启动运行时，退出终端时安全关闭。
3. **脚本与自定义客户端（[Web API](./webapi.md)）**：通过官方 Python / JS `openai` SDK 连接本机 `http://127.0.0.1:8787/v1` 或本机 Socket。

### `pipiclaw tui` 命令行参数

```bash
pipiclaw tui                                    # 打开 default 工位，自动续接上次终端对话
pipiclaw tui --here                             # 一键打开或自动创建当前目录专属工位（自动绑定工作目录）
pipiclaw tui --cwd .                            # 将当前打开工位（如 default）的工作目录设为当前仓库
pipiclaw tui --desk side-project --create       # 新建或打开指定名称的工位
pipiclaw tui --new                              # 在当前工位开启一段全新对话（长期记忆仍保留）
pipiclaw tui --print "用三句话总结当前仓库架构"     # 单次执行：输出最终答案后立即退出（支持管道输入）
```

| 选项 | 说明 |
|---|---|
| `--here` | 一键打开匹配当前目录 `cwd` 的已有工位；若无则自动按目录名创建专属工位并绑定当前目录（不可与 `--desk` / `--cwd` 同用） |
| `--desk <名称>` | 打开指定工位（省略时固定打开 `default`）。自动续接该工位上次使用的终端会话 |
| `--cwd <目录>` | 设置该工位的工作目录（如 `--cwd .`），等价于在对话中执行 `/desk cwd <绝对路径>` |
| `--create` | 工位不存在时先创建再绑定（等价于 `/desk new` + `/desk bind`） |
| `--new` | 不续接上次对话，直接开启新会话 |
| `--print`, `-p` | 非交互单次模式：执行参数或标准输入中的 prompt，打印结果后退出 |
| `--plain` | 使用行式纯文本界面替代全屏富终端 UI |
| `--quiet`, `-q` | 仅输出最终答复，隐藏中间进度提示（自动启用 `--plain`） |

**终端快捷键与实时状态**：
- 回合进行中按一次 `Ctrl-C`（或输入 `/stop`）立即中止当前回复；空闲时连按两次 `Ctrl-C`、按 `Ctrl-D` 或输入 `/exit` 退出终端。
- 终端空闲时会自动轮询会话新消息，因此后台作业完成、长程任务汇报等服务端主动推送也会实时显示在屏幕上。

## 工位（Desk）与频道（Channel）

理解这两个词，就能彻底搞清“什么东西共享、什么东西隔离”：

- **频道（Channel）** 是你说话的窗口：一个钉钉私聊（`dingtalk:dm:<staffId>`）、一个钉钉群（`dingtalk:group:<conversationId>`），或一个终端/API 会话（`webapi:conv_<id>`）。
- **工位（Desk）** 是一套独立的工作台（位于 `workspace/desk-<名称>/`），拥有自己的**长期记忆、工作日记、长程任务、定时事件与工作目录 `cwd`**。

核心规则：
- **默认共用 `default` 工位**：新私聊、新群聊与默认终端都会自动绑到 `default` 工位——**对话上下文各自独立互不串台，但共享同一份长期记忆与任务**（因此在私聊里交代的偏好，群里也会记得）。
- **需要隔离项目或群聊时新建工位**：如果你不想让私聊记忆进某个群，或者想把公司项目与个人副业分开，用 `pipiclaw tui --here`（或 `/desk new` + `/desk bind`）建个新工位即可。频道临时切到其他工位期间，**原工位的后台任务与任务模板事件照常推进**，汇报与提问安全暂存在原工位内，切回或执行 `/tasks adopt <id>` 后按序补发。
- **所有工位共享底色**：`workspace/` 根目录下的 `SOUL.md`（性格）、`AGENTS.md`（通用守则）、`MEMORY.md`（公共背景）、`skills/` 与 `sub-agents/` 由全实例所有工位共同使用（全局背景由用户维护，或应用户明确要求由助手用文件工具修改）。

### `/desk` 工位管理命令

| 命令 | 作用 | 忙碌时可用 |
|---|---|---|
| `/desk` 或 `/desk list` | 查看所有工位、当前工作目录、绑定频道与后台任务概况 | 是 |
| `/desk new <名称> [目录绝对路径]` | 创建新工位（名称为 1–32 位小写字母、数字或连字符 `-`，可选直接指定仓库目录） | 是 |
| `/desk cwd [绝对路径\|--reset]` | 查看、设置或重置当前工位的工作目录（有运行中任务步骤或写锁占用时拒绝切换） | 是 |
| `/desk bind <名称>` | 将当前频道切换到目标工位（若已归档会自动恢复；切回旧工位会接续原先对话） | 否（需等当前回合结束） |
| `/desk archive <名称>` / `unarchive <名称>` | 归档闲置工位（停止其定时事件，完整保留历史数据；`default` 不可归档）或恢复归档工位 | 是 |

## 助手忙碌时如何插话、排队与接管

同一个频道同一时刻只跑一个主对话回合，但你**永远不必干等它生成完**：

- **中途纠偏（`/steer <补充说明>`）**：在当前工具执行完毕后立刻把你的新要求注入本轮推理。在钉钉（默认 `busyMessageDefault: "steer"`）和终端里，**忙时直接发普通消息默认就是 `/steer` 的效果**。
- **排入下一轮（`/followup <下一件事>`）**：不打断当前回复，等这一轮完整结束后紧接着处理。
- **紧急叫停（`/stop`）**：立即中止当前聊天回复（钉钉端同时清空后续排队消息）。
  - ⚠️ **边界区分**：`/stop` **只停当前聊天**，绝不会误杀后台长程任务或已派发的外部 Coding Agent！暂停后台任务用 `/tasks pause <id>`，强杀委派子进程用 `/subagents cancel <runId>`。
  - 给正在后台跑的长程任务传话或回答问题，用 `/tasks msg <id> <内容>`（普通聊天消息不会直接进入独立任务会话）。

## 斜杠命令速查总表

发送 `/help` 查看分组总表，发送 `/help <命令名>` 查看带子命令的具体示例。未知的 `/xxx` 命令会被直接拦截提示，不会白白消耗大模型调用。

### ⚡ 随时可用（由本地运行时秒回，不消耗模型 Token，即使模型卡住也立即生效）

| 命令 | 用途 |
|---|---|
| `/help [命令名]` | 查看命令列表或单个命令的详细用法 |
| `/status` | 查看当前运行状态、所用模型（含凭据与备用模型状态）、上下文占用百分比与后台任务摘要 |
| `/stop` / `/steer <文本>` / `/followup <文本>` | 叫停当前回合 / 中途微调方向 / 排队下一条消息 |
| `/tasks [show\|log\|msg\|adopt\|pause\|resume\|cancel\|archive\|doctor]` | 查看、传话、接管汇报、暂停、恢复（可加 `+steps N` 或 `+usd X` 预算）、取消或诊断后台长程任务 |
| `/subagents [list\|show\|output\|cancel\|roles]` | 查看运行中与历史委派、读取实时产出尾部、强杀进程（`cancel <id\|all>`）或检查角色可用性 |
| `/events <list\|show\|delete\|history>` | 查看本工位定时事件、读取 JSON 定义、删除事件或核查触发历史 |
| `/desk [list\|new\|cwd\|bind\|archive\|unarchive]` | 查看与管理工位及工作目录（仅 `bind` 需空闲时执行） |
| `/usage [7d\|month]` | 查看今日/近 7 天/本月的本工位与全局 Token 消耗及账单估算明细 |
| `/context [detail]` | 查看系统提示词、工具 Schema 与动态上下文占用的体积明细 |
| `/skills [list\|show <名称>]` | 查看已加载的工作区与共享技能列表或具体内容 |
| `/new` | 立即建立全新对话会话（旧会话在后台完成记忆归档，长期记忆继续保留） |

### 🛋️ 空闲时可用（需等当前对话回合结束后执行）

| 命令 | 用途 |
|---|---|
| `/model [模型名或唯一片段]` | 查看当前与可用模型列表，或按 `provider/model`、模型名及唯一子串切换模型 |
| `/thinking [档位\|cycle]` | 查看或切换推理思考深度（`off` / `minimal` / `low` / `medium` / `high` / `xhigh` / `max`） |
| `/memory [status\|list [类型]\|show <名称>\|journal [日期]\|forget <名称>]` | 查看长期记忆统计、列表、单条详情、某天工作日记，或用 `forget` 物理删除并永久屏蔽某条记忆 |
| `/compact [保留重点说明]` | 手动压缩当前长对话上下文（可附带说明希望重点保留的上下文） |
| `/session` | 查看当前会话 ID、消息轮数、工具调用次数与累计花费 |
| `/reload` | 热重载外部修改过的技能、`models.json`、`auth.json`、`settings.json` 与角色目录 |

## 图片、文件收发与输出模式

- **发图片、语音与文件给助手**：钉钉私聊与群聊（需 @机器人）支持单图/富文本多图（每条最多 10 张、单张 ≤ 10 MiB）、语音识别（ASR 文本自动接入）、常规文件落盘（存入工位 `inbox/` 供工具读取）及引用回复上下文；Web API 支持 base64 图片与文件输入。图片识别需当前所选模型本身支持视觉输入（自定义模型需在 `models.json` 声明 `"input": ["text", "image"]`）。
- **助手发文件给你（`send_media`）**：在钉钉中，助手生成的报告、表格、截图或压缩包可直接作为原生图片或可下载附件推到聊天窗；终端与 Web API 无附件通道，助手会直接告知文件的本机路径。
- **钉钉流式卡片展示模式**：通过 `channel.json` 的 `dingtalk.responseMode` 调节（默认 `full_progress_then_plain_final` 累积进度后另发结论，可选 `rolling_progress_then_plain_final` 滚动最近 5 条进度或 `final_card_only` 仅发结果卡），详见 [配置字段参考](./configuration-reference.md#responsemode-行为矩阵)。

## 界面用语与内部术语对照

如果你同时阅读设计文档（Specs）或架构文档，聊天界面上的中文词与内部机制词对应关系如下：

| 界面展示用语 | 架构 / 设计文档术语 | 界面展示用语 | 架构 / 设计文档术语 |
|---|---|---|---|
| 回合 | turn | 工作日记 | journal |
| 任务说明 / 工作项 / 任务记录 | contract / team board / loop log | 后台整理 | reflect pass |
| 等结果 / 等你回复 / 等到 HH:mm | `waiting`（`work` / `user` / `time`） | 观察期 / 已记入忽略名单 | probation / tombstone |
| 投递频道 | 事件 `channelId`、任务 `channel` | 随时可用 / 空闲时可用 | 运行时控制命令 / 会话命令 |
